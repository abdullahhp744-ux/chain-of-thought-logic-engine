# Chain-of-Thought Logic Engine

## Overview

This project demonstrates how Chain-of-Thought (CoT) prompting improves AI reasoning by forcing structured problem solving and self-correction before generating the final answer.

## Features

- Structured reasoning
- Self-correction
- Logic trap testing
- Hallucination reduction
- XML-based reasoning format
